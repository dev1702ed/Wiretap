# Live and benchmark extras (P5), pinned to exact versions in P5.1 (A1): the
# versions the P5.1 sandbox runs measured with. Install everything, the three
# packages included, in ONE command so the constraints apply to all of it:
#
#   pip install -c benchmarks/constraints.txt -e "./sdk-python[dev]" -e "./backend[dev]" -e "./bridges/openlineage[dev]" -r benchmarks/requirements.txt
#
# benchmarks/constraints.txt pins the transitive versions that affect
# measurement (sqlglot, networkx, fastapi, ...). benchmarks/run.py compares what
# is installed with both files and records any mismatch in its environment
# table (a warning, never a failure). The SDK itself takes no new runtime
# dependency. Unit tests (benchmarks/tests) need none of these; run.py skips any
# stage whose library is missing.
#
# Python 3.10 cannot install ipykernel 7.4.0 (it needs 3.11+), so 3.10 gets the
# newest release that supports it, exactly as pip resolved it in the sandbox.

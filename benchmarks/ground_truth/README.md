# Ground truth testbed

A known flow with a hand-written expected graph. Establishes that DCP's capture is
*correct* before any claim is made about what it captures that others do not.

Order matters: precision/recall here must land before the adversarial results mean
anything. An instrument that has not been shown accurate cannot be used to measure a gap.

Expected graph lives in `expected_graph.json` (P0), written by hand, never generated by DCP.
